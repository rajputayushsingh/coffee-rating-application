# ☕ Coffee Rating Application

A full-stack Coffee Rating Application where users can view different coffee blends, vote for their favorite coffee, and see a live leaderboard based on votes.

## 🚀 Features

- Display coffee blends in a responsive grid
- Vote for your favorite coffee
- Store votes in MongoDB
- Dynamic vote updates without page refresh
- Top-rated coffee leaderboard
- REST API using Express.js
- MongoDB Atlas database
- Responsive frontend

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- REST API
- Nodemon
